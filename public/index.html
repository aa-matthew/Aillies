Ready when you are

Connect once. Choose any time.

  1. Install Codex CLI on each peer and run codex login with your ChatGPT account. An existing desktop login alone may not authenticate the CLI.
  2. Enable SSH on each peer: Remote Login on macOS, or OpenSSH Server on Ubuntu.
  3. Add a host alias in ~/.ssh/config on this machine. Set its HostName, User and IdentityFile.
  4. Run ssh ubuntu-home manually to verify its host key and key-based login. Ensure bash -lc 'codex --version' works on the peer.
  5. Add that alias above and select it as your middleman.

This prototype sends requests from this screen. It does not intercept the existing ChatGPT or Codex desktop app or transfer their cookies. Both machines must be online.

Optional HTTPS traffic routing

A loopback CONNECT proxy is available at . It routes allowed OpenAI HTTPS destinations through the selected peer, but keeps the requesting client's authentication. App proxy support must be verified separately. Changing the selection affects new connections; existing tunnels keep their route.
