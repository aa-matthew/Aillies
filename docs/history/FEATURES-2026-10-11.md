GPT 6.1 Sol text routing uses the Responses Lite format, including repeated normalization on both devices. Both A and B must run the corrected build. Hosted image requests retain their existing format; live image support for this model remains unverified.

The `request-compat-v2` formatter uses Lite only for GPT 6.1 Sol, GPT 6 Sol and GPT 6 Luna text without hosted web search/images. Ordinary requests lift prefixed tools, omit the backend's standard-tier and parallel-call fields, and preserve history. Fast permission is still enforced before wire formatting. Regression coverage is mocked; live acceptance remains unverified.

### Router core v3

New installers align the client identity and request core with pinned 9router: default instruction text when absent, model/effort alias conversion, function schema normalization, stable session/cache keys and preserved Lite developer IDs. Session headers are bounded and carried as a cache key across the peer link; arbitrary headers and credentials are not forwarded. Unknown tools/fields and server-only references still fail closed. The new diagnostic build marker is router-core-v3. It is an independent client and does not imply OpenAI endorsement.

## macOS quit, switch and reopen (alpha.8)

The provider selector offers a compact review when Codex is still running, followed by **Quit, switch & reopen** or Cancel. It names the apps that will close (including an editor when it owns Codex) and terminal count. Finish work/save editor changes first. Aillies quits normally, verifies shutdown, runs the history-preserving transaction and opens only ChatGPT. Editors and terminal Codex sessions stay closed. A previously quit ChatGPT is found in standard Applications locations. The chosen provider stays selected while awaiting confirmation or switching; Cancel/failure restores the actual provider. No unfinished action is resumed automatically. Unknown clients refuse; recovery failures keep Codex closed. Windows/Linux still use manual quit/reopen. Implementation: `aillies-codex/src/restart.rs` and `restart/macos.rs`, Node plan/execute methods, thin desktop IPC, `app.js`.

Existing-chat switching includes indexed same-provider rollout copies without deleting/merging history or applying canonical paginated offsets twice. Older provider-setting events without thread IDs are supported within their validated rollout. Conflicting copies or ambiguous unindexed histories still stop safely.

Alpha.9 removes the two-second history preparation cutoff. The provider row shows scanning, preparation counts and saving status while the existing background worker runs. The provider choice stays pending until commit; errors remain visible. Clients must stay closed, and transactional rollback/recovery, record bounds and path/schema checks remain.

## Alpha.11 provider and pairing controls

Home and the tray replace routing pause/resume with the existing transactional Normal ↔ Aillies provider switch. Use Aillies with groups Codex and disabled Claude Code — Upcoming. Selecting Aillies explicitly resumes a previously paused connection; selecting Normal leaves peer sharing independent. Allow Fast mode appears only while Share this device is on. Pair a device goes directly to code entry, then the existing matching-code/both-device approval flow; no OpenAI token exchange. Tray provider actions open the same pending selection/restart review, and Quit requires Normal before stopping the node. The user-supplied silver A and wordmark are preserved in assets/brand/source, with derived platform icons generated by scripts/brand-icons.mjs. Physical native tray/restart and fresh live image acceptance remain unverified.
