# Aillies 1.2.0 — Signed updates and network recovery

Aillies can now download verified whole-app updates and recover selected device connections after network changes or wake-up.

- Check for stable updates automatically or in Connection details. Choose **Update & restart** after the signed download is verified. Aillies waits for active requests; **Later** keeps the current version running.
- Recheck the selected Codex and Claude devices after network changes and wake-up. Keep device identity, approvals, accounts and destinations; show **Reconnecting…** while recovering. No additional inference replay or fallback is introduced.
- Export the latest100 network events in Diagnostics without SSIDs, network addresses, location, chat content or credentials. Ignore stale connection checks after network changes.
- Older pairings containing only private-network addresses may need one new full-code pairing for internet connectivity.

## Installation and updates

**Users on 1.1.3 or earlier: install 1.2.0 manually once.** Those versions have no built-in updater. Subsequent stable releases can be delivered through the signed updater feed.

Downloads: Apple Silicon macOS13+ DMG, Windows x64 NSIS installer, Linux x64 DEB/AppImage, CLI archives and source. `latest.json` supplies the Mac Apple Silicon, Windows x64 and Linux AppImage update packages and signatures. DEB and Intel Mac CLI users continue to update manually.

## Verification and limits

Local checks passed:257 Rust tests, UI behavior and release/feed checks, strict Clippy/formatting, installed-Codex mock smoke and Windows desktop MSVC cross-check. Publication is gated on native macOS/Windows/Linux checks/builds and real Tauri verification of every updater package. Simulated Iroh recovery preserves pinned identity/grants and submits no extra upstream work.

Mac is ad-hoc signed and **not Apple-notarized**; Windows is unsigned. Updater signatures do not replace OS code signing. Physical installed-app upgrades and Wi-Fi/hotspot/VPN/sleep handover remain acceptance work. Claude support remains experimental; provider authorization and applicable service terms still govern use. No Apple, OpenAI or Anthropic endorsement is claimed.
