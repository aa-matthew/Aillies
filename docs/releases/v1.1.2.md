# Aillies 1.1.2 — Claude sender defaults and clearer internet pairing

- Default missing, null and unspecified Claude generation effort to medium on the sending device before local execution or forwarding to a paired computer. Explicit effort, structured outputs and signed history stay intact; native model compatibility rules still apply.
- Diagnostics separates original incoming, sender outgoing and effective upstream effort. Older logs show Not recorded instead of a guessed value.
- Internet pairing is the default on both computers. Full Iroh codes are prominent and easy to copy; eight-digit pairing remains under Same private network. Both computers still approve.
- Repair the reported Windows Tao COM apartment panic by initializing UI STA before startup, moving connection startup to a worker and disabling unused file-drop handlers. Tray opens are serialized, hidden/minimized/off-screen windows recover, and native startup errors remain available.

Accounts, pairings and chat histories are preserved. Claude remains experimental. Native CI verifies Windows-specific COM regressions; physical window behavior on the reported PC and live account entitlement remain separate acceptance. Mac is ad-hoc signed/unnotarized; Windows is unsigned. Previous releases and assets remain unchanged.
