# Aillies 1.1.3 — Preserve settings and recover write access

- Accept valid multiline Codex TOML when activating and restoring routing. Preserve unrelated settings, comments, later edits and chat content. Invalid or ambiguous managed settings still fail safely.
- Detect settings access failures before closing clients or migrating history. Diagnostics exports the latest 100 fixed settings events without config values, paths or credentials.
- Add **Grant write access** recovery on macOS, Windows and Linux. Try current-user repair first; request native administrator approval only after a permission denial. Recheck access, then let you review and retry the switch.
- Keep the main app unprivileged. The repair helper only changes metadata for allowlisted default settings paths; custom locations, unsafe links and system policy restrictions require individual help. **Quit anyway** remains available.

Accounts, pairings and chat contents are preserved. Claude remains experimental. Native OS checks/builds and synthetic tests do not replace physical administrator-prompt acceptance. Mac packages are ad-hoc signed/unnotarized; Windows installers are unsigned. Previous releases remain unchanged.
